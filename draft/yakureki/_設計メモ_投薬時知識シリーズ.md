# 投薬時に使える知識シリーズ 設計メモ

薬歴マニュアル（draft/yakureki/）内で育てる新シリーズの設計方針。書き手やセッションが変わっても方針がぶれないよう、**決まったことだけ**を置く。このメモ自体は公開ページではない（内部の設計用）。

最終更新：2026-07-17

---

## このシリーズは何か

投薬時に患者から返ってきた訴えを、**薬剤性か別の原因かに切り分け、次の一手を決める**ための資料。

リファレンス実物：`循環器_高血圧.html`（Ca拮抗薬のむくみ／ACE阻害薬の咳）

既存の声掛け集・テンプレート集との違いは、**返ってきた答えの読み方**を持っていること。声掛け集は投げる球しか載っておらず、カウンターで難しいのは球を投げることではなく答えの処理だった。機序が分かっていれば聞き方は自然に決まるが、分からないまま聞くと返ってきた答えを受け取れない。

裏付けのある知識があれば、テンプレートをそのまま貼らずアレンジできる。通則(5)「定型文を用いて画一的に記載するのではなく」への対応も、免責文で注意するより**なぜそう書くかを理解した人がテンプレを使う構造**にするほうが根本的に効く。

---

## 二層構造（正本の所在・最重要）

| 層 | 中身 | 例 |
|---|---|---|
| **部品（正本）** | 訴え × 薬効群。機序と切り分けを**ここに一回だけ**書く | むくみ／乾いた咳／ふらつき／こむら返り／徐脈 |
| **入口** | 疾患・背景・季節で部品を束ね直し、**差分だけ**書く | 心不全／脳卒中既往／腎機能低下／夏 |

**なぜ二層にするか：** 同じ訴えでも背景疾患で読み方の初期値が反転するため。

- 高血圧のみ → むくみ＝まず薬剤性を疑う。体重が増えていなければ経過観察側
- 心不全あり → むくみ＝まず増悪を疑う。同じ訴えでも初期設定が逆

疾患切り口だけにすると、Ca拮抗薬のむくみの説明が高血圧・狭心症・心不全の各ページに三重に書かれ、正本が壊れる。部品が正本なら、入口を何枚増やしても中身は一つで済む。訴えから引く・疾患から引く・季節から引く、と入口が増えるほど部品への投資が回収される。

**入口ページの構成：** ①処方から背景を読む（薬剤師は病名を知らされず処方から推定する。これ自体がこのシリーズらしい知識になる）／②この背景での読み替え・優先順位／③この背景特有の確認／④部品カードへのリンク

## 型の仕様

カード1枚 ＝ 4セクション。**セクション名は固定。ただし全部は埋めない。**

| セクション | 扱い | 中身 |
|---|---|---|
| なぜ確認するのか | **必須** | 機序。理由が分かれば聞き方は自然に決まる |
| 返ってきた答えの読み方 | 任意 | 切り分けが存在するネタだけ。見分け表がカウンターで一番効く |
| どう動くか | 任意 | 条件 → 対応のグリッド |
| 薬歴に残す | **必須** | 確認 → 結果 → そのうえで指導、の順 |

「家庭血圧の測り方」に見分け表はなく、「季節の話題」に切り分けはない。ないセクションを無理に埋めると水増しになり、型を守るために書けるネタを捨てるのも損。

**記載例の区別（事故防止）：**

- **申し送り** … 汎用文。そのままコピーしてよい。グレータグのまま
- **A／P** … 患者固有の事実が埋め込まれている。**無編集で貼ると即「テンプレの丸写し」の記載になる**。タグ等で「書き換え前提」と見た目で分かるようにする。コピーボタン自体は外さない
- **実装済みの形（2026-07-17確定）** … A／Pは黄タグ「A／P・要書き換え」＋枠を破線に。末尾の免責ボックス（記載例の取り扱い）に「固有の事実を置き換えて使う」旨を明記し、このボックスはテンプレのみ表示でも隠さない

## 既存ページの整理（型の確定と同時に実行）

- `テンプレート_循環器.html` … 記載例が二重管理になる。循環器_高血圧がタブ切り替えを持った時点で**吸収して引退**。並存させると必ず食い違う。**引退の実行タイミング（2026-07-17判断）：** タブは実装済みだが、同ページの高血圧グループ（安定期の申し送り・A／P、家庭血圧・ふらつき）の受け皿カードがまだない。**「家庭血圧の測り方」「ふらつき・立ちくらみ」カードを書く回で吸収してから引退する**。心不全〜弁膜症のグループは各疾患ページ（入口）ができるまで残す
- `声掛け_降圧剤.html` … ページとして解体し**素材にする**。「副作用の観察」カードは部品カードへ吸収。「家庭血圧の測り方」「目標値を聞かれたとき」「季節の話題」も4部構成の知識ネタとして書き直せる

**タブ切り替え：** `ハイリスク_血液凝固阻止剤.html` の `解説＋テンプレ／テンプレのみ` 方式を踏襲する。急いでいる人はテンプレのみで薬歴に直行、学習したい人は通読。**これで正本問題も同時に解決する**（テンプレは知識ページの中に住み、タブは同じ要素を絞り込んで見せるだけなので、正本は常に一つ）。

**実装済み（2026-07-17、循環器_高血圧で型確定）：**

- テンプレのみ側に残すもの ＝ **カード見出し＋見分け表＋記載例＋末尾の免責ボックス**。見分け表はカウンターで引く頻度が高いため残す決定
- 仕組み ＝ `.tpl-toggle` ボタン＋ `body.tpl-only` クラス。残す要素は `:not()` の除外（`.card-title` / `.tpl`）と opt-in クラス `tpl-keep`（見分け表）、隠すカード・序文は `only-full`
- 選択状態の localStorage キーはハイリスク系と共通の `yakureki-tpl-only`（マニュアル内でモードが引き継がれる）
- 新カードを書くときの約束：見分け表の `.cmp-wrap` に `tpl-keep` を付ける／テンプレを持たないカードは `only-full` を付ける

## 裏取りのルール（厳守）

**中身は最新の一次資料で書き下ろす。** 過去の社内勉強会資料は切り口の当たり付けにのみ使い、**引用も出典表記もしない**（古い版が混ざり、資料の信頼性を下げるため）。

無料で当たれる一次資料：

- **JSH2025**（高血圧管理・治療ガイドライン2025）… 公開状況は執筆時に確認する。**降圧目標値はJSH2019から変わっている可能性が高い。記憶で書かず必ず現物を見る**
- **日本循環器学会ガイドライン**（心不全2025年改訂版ほか）… 学会サイトで無料公開。疾患入口ページの正確性はこれでほぼ担保できる
- **PMDA 添付文書・インタビューフォーム** … 副作用の頻度・発現時期・機序の正本
- **重篤副作用疾患別対応マニュアル**（厚労省・PMDA）… 受診につなぐ目安の裏取りに向く

**運用：** 機序・切り分けの枠組みは書き下ろす → **固有の数値・期間・閾値は必ず一次資料と突き合わせてから確定する**。出典は**HTMLコメントで各カード直下に残す**（公開表示には出さない）。数年後の改定時に、どの記述をどこと突き合わせたか追える。

**最終レビューは薬剤師（木村）。** 受診勧奨の基準・臨床的な言い切りは公開前に必ず目を通す。

## 切り口の当たり（未検証の仮説）

過去の社内資料から拾った枠組み。**そのまま載せない。最新の一次資料で組み直すこと。**

- **厳格に下げたい患者像** … 抗血栓薬使用中（特にDAPT）／抗凝固療法中／糖尿病合併。つまり脳梗塞後・心筋梗塞後・心房細動。疾患入口ページの骨格になる
- **下げすぎに注意する患者像** … 脳血管の高度狭窄／冠動脈が狭いまま／虚弱高齢者。「血圧を下げすぎて大丈夫か」と聞かれたときの答えの骨格になる
- **シリーズの序文になる問題意識** … 薬剤師のクリニカルイナーシャ。「夏場は下がりすぎるので気をつけて」「130/80台で安定してますね」を誰にでも毎回言うのは、患者個別の背景を無視した指導であり、コントロール不良を助長しうる
