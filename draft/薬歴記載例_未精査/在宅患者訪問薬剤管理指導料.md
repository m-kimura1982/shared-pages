# 在宅患者訪問薬剤管理指導料 — 薬歴記載例のたたき台（未精査）

作成 2026-08-19 ／ `/加算ページ` 手順6。**精査前に薬歴マニュアルへ書き込まないこと。**

## 記載項目（根拠）

別添3 区分15・１(10)。薬学管理料 通則(4)の記載事項に**加えて**ア〜カ。

| | 項目 |
|---|---|
| ア | 訪問の実施日、訪問した保険薬剤師の氏名 |
| イ | 処方医から提供された情報の要点 |
| ウ | 訪問に際して実施した薬学的管理指導の内容（薬剤の保管状況、服薬状況、残薬の状況、投薬後の併用薬剤、投薬後の併診、患者の服薬中の体調の変化（副作用が疑われる症状など）、重複服用、相互作用等に関する確認、実施した服薬支援措置等） |
| エ | 処方医に対して提供した訪問結果に関する情報の要点 |
| オ | 処方医以外の医療関係職種との間で情報を共有している場合の、提供された情報の要点と提供した訪問結果の要点 |
| カ | 在宅協力薬局が訪問した場合は(4)イの事項 |

あわせて、薬学的管理指導計画書を薬歴に添付する等の方法により保存する〔(5)イ〕。

## 記載例のたたき台

### 定期訪問（初回）

- **ア**　○年○月○日 訪問／訪問薬剤師：○○
- **イ**　○○クリニック ○○医師より、訪問薬剤管理指導の指示。診療情報提供書にて、△△（疾患）で□□錠を継続中、ADL低下により自己管理が困難との情報を得た。
- **ウ**　保管状況：居間の引き出しに一包化を保管。直射日光・高温は避けられている。／服薬状況：朝食後の飲み忘れが週2〜3回。/残薬：□□錠 14日分。/併用薬・併診：△△病院皮膚科より軟膏の処方あり（お薬手帳で確認）。重複・相互作用なし。/体調の変化：ふらつき・転倒なし。/服薬支援措置：日付入りの一包化に変更し、服薬カレンダーを設置。
- **エ**　○○医師へ訪問結果を文書で報告。残薬14日分と飲み忘れの状況、服薬カレンダー導入について情報提供し、次回処方日数の調整を依頼。
- **オ**　担当ケアマネジャー○○へ、服薬カレンダーの設置と声かけの依頼を文書で情報提供。訪問介護からは「朝の訪問時に服薬済みか確認できる」との回答を得た。

### 定期訪問（2回目以降・経過を書く形）

- **ア**　○年○月○日 訪問／訪問薬剤師：○○
- **イ**　前回報告後、○○医師より□□錠の日数を28日から14日へ変更する旨の連絡あり。
- **ウ**　保管状況：変化なし。/服薬状況：服薬カレンダー導入後、飲み忘れは週1回程度に減少。/残薬：□□錠 3日分（前回14日分から減少）。/併用薬・併診：変更なし。/体調の変化：ふらつきなし、血圧は自宅測定で○○台で安定。/服薬支援措置：カレンダーの位置を食卓へ移動。
- **エ**　○○医師へ、残薬が3日分まで減ったこと、飲み忘れの頻度が下がったことを文書で報告。
- **オ**　ケアマネジャー○○へ同内容を情報提供。

### 在宅協力薬局が代わって訪問した場合（カ）

- 在宅協力薬局側：上記ア〜オを薬歴に記載し、**在宅基幹薬局と記録の内容を共有した旨**を残す。
- 在宅基幹薬局側：**在宅協力薬局名と訪問日**を残す（処方医への報告は在宅基幹薬局が行う）。

## 判断に迷った点・確認してほしいこと

1. **ウが長い。**通知が列挙している確認項目（保管・服薬・残薬・併用薬・併診・体調変化・重複・相互作用・服薬支援措置）を全部書くと定型の羅列になり、通則(5)「定型文を用いて画一的に記載するのではなく」と衝突しかねない。**毎回全項目を書くのか、変化があった項目を書いて他は「変化なし」でよいのか**、社内の運用を決めたい。

2. **確認と指導の書き分け。**上のたたき台は確認結果に寄っている。薬歴側のルール（確認 → 結果 → そのうえで指導）に沿うなら、指導した内容をもう1行足す形になる。どこまで書くか。

3. **エの「要点」の粒度。**訪問結果報告書の写しを薬歴に添付する運用なら、薬歴側は「○○医師へ文書で報告（写し添付）」で足りるのか、要点も書くのか。服薬情報等提供料では「写し又は要点」で足りる旨を薬歴ページに書いているので、揃えるかどうか。

4. **オは該当がないときに書かないでよいか。**通知は「情報を共有している場合にあっては」なので、共有していなければ記載不要と読める。ただし在宅は多職種連携が前提なので、実際にはほぼ該当する。

5. **薬学的管理指導計画書の見直し記録。**「少なくとも1月に1回は見直し」とあるが、見直した事実をどこに残すか（計画書側の更新日で足りるか、薬歴にも残すか）。
