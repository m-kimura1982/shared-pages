## 1. 記載項目（根拠）

### （A）服薬管理指導料に加算した場合（22点）

別添3「１０の３」５には固有の薬歴記載事項の定めがない。根拠は **薬学管理料 通則(5)**
「薬学管理料やその加算を算定する場合には、その根拠及び指導内容等について簡潔に記載すること」。

算定要件（別添3「１０の３」５(1)）から逆算すると、薬歴に残るべきものは次のとおり。

1. 調剤後に電話等で連絡した事実（日付・方法）
2. 確認した内容 … 服用状況／残薬の状況／保管状況／鎮痛等の効果／服薬中の体調の変化の有無
3. 確認結果を踏まえて行った指導の要点（保管取扱い上の注意、残薬の適切な取扱方法を含む）

> **注意（第2段階で要確認）**
> 2026改定の通知(1)は「**調剤後、継続的に電話等により**〜確認し」となっている。
> 窓口での説明だけで算定できるかどうかは、この文言の読み方次第。記載例も「窓口＋後日の電話」で
> 組んである。ここは木村さんの判断が要る（後述「要確認」）。

### （B）在宅の点数に加算した場合（100点）

別添3「１５」２(4)／「１５の２」(9)エ／「１５の３」(9)エ に個別の記載事項がある。
通則(4) と 本体（訪問・緊急訪問・緊急時等共同指導）の記載事項に **加えて** 次を記載する。

- ア 訪問に際して実施した麻薬に係る薬学的管理指導の内容
  （保管管理状況、服薬状況、残薬の状況、麻薬注射剤等の併用薬剤、疼痛緩和等の状況、
  　麻薬の継続又は増量投与による体調の変化の有無 などの確認等）
- イ 訪問に際して行った患者・家族への指導の要点
  （麻薬に係る服薬指導、残薬の適切な取扱方法も含めた保管管理の指導等）
- ウ 処方医（緊急訪問・緊急時等共同指導では在宅療養を担う保険医療機関の保険医）へ提供した
  　訪問結果に関する情報の要点
- エ 返納された麻薬の廃棄に関する事項（麻薬廃棄届の写しの添付でよい）

## 2. 記載例のたたき台

### （A）服薬管理指導料 ＋ 麻薬管理指導加算（22点）

**オキシコドン徐放錠の新規開始・調剤後に電話でフォローした場合**

```
S）（窓口）「痛みで夜眠れない日がある。麻薬と聞いて少し怖い」
　　（R〇.〇.〇 電話）「飲み始めてから夜は眠れるようになった。吐き気は2日で治まった」

O）オキシコドン徐放錠5mg 1回1錠 1日2回（12時間毎）、新規開始。
　　レスキュー：オキノーム散2.5mg 疼痛時。制吐剤・下剤の併用あり。
　　R〇.〇.〇 電話にて確認。服用状況＝指示どおり2回/日、飲み忘れなし。
　　残薬＝レスキュー〇包（〇日で〇回使用）。保管＝本人管理、他者の手の届かない場所に施錠なしで保管。
　　鎮痛効果＝夜間の疼痛は消失、NRS 7→3。
　　体調の変化＝悪心は開始2日で消失、便秘なし、眠気・呼吸抑制を疑う症状なし。

A）鎮痛は得られており、レスキューの使用回数も減少。定時量の増量は要さないと考えられる。
　　保管場所が家族・来客の目に触れる場所であり、紛失・誤用の懸念がある。
　　残薬（未使用のレスキュー）の取扱いを本人が把握していない。

P）（指導）保管は本人以外が触れない場所にまとめること、他人への譲渡が禁じられていることを説明。
　　残った麻薬は自己判断で廃棄・保管せず、必ず薬局へ返却するよう依頼。
　　レスキュー使用の記録（日時・効果）をメモに残すよう依頼。
　　次回受診時に疼痛の推移とレスキュー回数を医師へ伝えるよう説明。
　　次回も調剤後に電話でフォローする。
```

**（要検討）短縮版**

```
R〇.〇.〇 電話にてフォロー。服用状況＝指示どおり、飲み忘れなし。残薬＝レスキュー〇包。
保管＝本人管理・家族の目に触れる場所。鎮痛効果＝NRS 7→3、夜間痛消失。
体調の変化＝悪心消失、便秘・眠気なし。
指導＝保管場所の変更、譲渡禁止、残薬は薬局へ返却するよう説明。
```

### （B）在宅患者訪問薬剤管理指導料 ＋ 麻薬管理指導加算（100点）

```
【麻薬に係る薬学的管理指導】（記載事項ア）
　保管管理状況：仏間の引き出しに施錠して保管。管理は長女。
　服薬状況：定時のオキシコドン徐放錠は指示どおり。レスキューは1日1〜2回使用。
　残薬：徐放錠〇錠（次回訪問まで不足なし）、オキノーム散〇包。
　併用薬剤：麻薬注射剤の使用なし。制吐剤・下剤を継続。
　疼痛緩和等の状況：安静時NRS 2、体動時NRS 5。夜間の中途覚醒なし。
　体調の変化：増量後も眠気の増強なし。便秘はセンノシド調整で改善。呼吸抑制なし。

【患者・家族への指導】（記載事項イ）
　施錠保管の継続を確認。レスキュー使用の間隔（〇時間以上あける）を長女へ再説明。
　未使用の麻薬は自宅で処分せず薬局へ返却するよう依頼。

【処方医への情報提供】（記載事項ウ）
　R〇.〇.〇 〇〇クリニック〇〇医師へFAXにて報告。
　要点：体動時痛が残存しレスキュー1〜2回/日。眠気の増強なし。定時量の増量を検討いただきたい旨。

【返納された麻薬の廃棄】（記載事項エ）
　オキノーム散2.5mg 〇包を家族より返納。麻薬廃棄届（R〇.〇.〇 提出）の写しを添付。
```

## 3. 判断に迷った点・確認してほしいこと

1. **【最重要】外来22点の「調剤後、継続的に電話等により」の読み方。**
   2026の通知(1)は調剤後の電話等によるフォローを前提とした書きぶりになっている。
   窓口での確認・指導のみで算定してよいか、後日のフォローが要るかで、薬歴の型が変わる。
   ここが決まらないと記載例（A）は確定できない。

2. **確認と指導の書き分け。** 上の例では O に「確認したこと」、P に「指導したこと」を寄せた。
   薬歴マニュアルの型（確認 → 結果 → そのうえで指導）に合っているか要確認。

3. **保管状況の書き方。** 「保管状況を確認した」だけだと個別指導で「何を確認したか分からない」
   と指摘されうる。上の例では場所・管理者まで書いたが、毎回ここまで書くかは運用判断。

4. **在宅の（ウ）情報提供の要点。** 提供文書の写しを薬歴に添付する運用であれば、薬歴側の記載は
   要点のみでよいか（通則(5)は「写し又はその内容の要点等を記載又は添付」）。社内運用の確認要。

5. **緊急時等共同指導料の場合。** 通知(9)アには情報提供の要件がない（「必要な薬学的管理指導を
   行った場合」）が、記載事項エ(ハ)には「保険医に対して提供した訪問結果に関する情報の要点」が
   残っている。カンファレンスの場での共有をどう書くかを決める必要がある。
