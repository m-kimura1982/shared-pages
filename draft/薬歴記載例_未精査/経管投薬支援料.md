## 記載項目（根拠）

| 項目 | 根拠 |
|---|---|
| 固有の記載事項の定めはない | 別添3 区分15の7 に薬歴の定めなし |
| 算定の根拠及び指導内容等を簡潔に記載 | 別添3 薬学管理料 通則(5) |

※ `yakureki/加算別記載一覧.html#keikan` に「記載項目ポイント」として
「実際に残す内容」「支援を始めた経緯」が既に載っている。記載例（実際の文章）はまだない。

## 記載例のたたき台

### 保険医療機関からの求めで支援した場合

```
【経管投薬支援】R〇.〇.〇
経緯：〇〇病院〇〇医師より、胃瘻からの投薬に切り替えるため簡易懸濁法の可否を確認したいと
   依頼あり。本人及び長男に説明のうえ同意を得て実施。
確認：現在の処方〇剤について、簡易懸濁法の適否を確認。〇〇錠は崩壊・懸濁が可能。
   〇〇錠は徐放性製剤のため簡易懸濁に適さず、〇〇（代替）への変更を〇〇医師に提案し了解を得た。
   チューブは〇Frで、〇〇の懸濁後の通過性に問題なし。
指導：長男に対し、55℃の温湯約20mLで10分程度懸濁させる手順、崩壊しないときの対応、
   注入後にチューブを微温湯でフラッシュすることを実演して説明した。
   投与時刻ごとの薬の組み合わせを一覧にして手渡した。
評価：長男が手順を復唱でき、実際に1回分を実施できた。理解は良好。
```

### 家族等の求めで支援した場合（経緯のみ差し替え）

```
経緯：長男より「錠剤が詰まって流れないことがある」と相談あり。
   〇〇医師に連絡し簡易懸濁法へ変更することの了解を得たうえで、本人及び長男の同意を得て実施。
```

## 判断に迷った点・確認してほしい点

1. **算定要件が「支援を行ったこと」なので、薬歴は支援の内容が主役になる。** 上のたたき台は
   経緯 → 確認 → 指導 → 評価 の順にした。通則(5)が求める「算定の根拠」は、
   経緯（求めの有無・医師の了解・同意）と確認（簡易懸濁法の適否を判断した事実）が担う想定。
2. **医師の了解と患者の同意は必ず書き分ける。** イの場合（家族等の求め）は
   医師の了解が算定要件なので、薬歴に残っていないと算定根拠として不十分になる。
   ここは記載例の中でも落とさないようにしたい。
3. **温度・時間・チューブサイズなどの具体値**（55℃・10分・〇Fr）は簡易懸濁法の一般的な手順として
   書いたが、改定資料には出てこない。当社の手順書に合わせる必要があるので、
   数値を残すか「当社手順に従い」とするかは要判断。
4. **算定は1回だけだが、2回目以降の支援も薬歴には残る。** 2回目以降は算定しないので
   「経管投薬支援」の見出しを使うと算定したように見える恐れがある。見出しの付け方を
   薬歴マニュアル側で決めたい。
