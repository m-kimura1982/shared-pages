# 在宅患者緊急訪問薬剤管理指導料 — 薬歴記載例（未精査）

作成 2026-08-25。加算ページ（`加算まとめ/在宅患者緊急訪問薬剤管理指導料.html`）に置いていた ×／○ の記載例を、木村さんの指摘を受けて撤去したときの控え。
**掲載先候補：`yakureki/加算別記載一覧.html#zaitaku-kinkyu`。木村さんの確認後に反映する。**

## 記載項目（原文どおり）

別添3 区分１５の２ (8) ア〜エ。※ イ は令和8年5月29日の訂正通知で「緊急の要請」→「予め定めた訪問の計画以外の要請」に改まっている。

| | 原文 |
|---|---|
| ア | 訪問の実施日、訪問した保険薬剤師の氏名 |
| **イ** | 保険医から予め定めた訪問の計画以外の**要請があった日付**及び当該**要請の内容**並びに当該要請に基づき**訪問薬剤管理指導を実施した旨** |
| ウ | 訪問に際して実施した薬学的管理指導の内容（服薬状況、副作用、相互作用等に関する確認等を含む。） |
| エ | 保険医に対して提供した訪問結果に関する情報の要点 |

**イは「日付」で、時刻は求めていない。**（時刻を求めるのは夜間・休日・深夜訪問加算の (16)ウ ＝ 処方箋の受付時間と訪問した時間。混同しやすい）
**「誰から」「理由」も原文の記載項目ではない。** イが列挙しているのは 日付 ／ 要請の内容 ／ 実施した旨 の3つ。

## 加算ページから撤去したもの（記載例は薬歴マニュアルが正本）

**旧○例（不採用）**

```
R〇.〇.〇　〇〇クリニック・〇〇医師より電話にて、帯状疱疹に対しアメナリーフを本日から開始したいため、
本日中に薬剤を届けて服薬指導を行うよう依頼あり。同日、計画外で訪問し薬学的管理指導を実施。
```

木村さんの指摘（**記載例を書くとき全般に効く**）。

- **薬剤名を文中に入れない。** 「帯状疱疹に対しアメナリーフを本日から開始したいため」のような書き方は、**処方は見れば分かるし、薬が多い場合そもそも書けない。** 「帯状疱疹発症のため〇〇医師から緊急訪問指示あり」のように**要請の内容を簡潔に**。
- **「同日、計画外で訪問し薬学的管理指導を実施。」で終わらせない。** 曖昧な記録。**ウ（指導内容）は通常の訪問で記載する要領と同じで、何を聞き取って何を指導したかを具体的に書く。**
- ×／○ の対比そのものが「実務的に役に立たない」。

**加算ページ側は原文（ア〜エ）＋薬歴マニュアルへのリンクだけにした。** 記載項目を言い換えた箱も、原文から逸脱しやすいので置かない（木村さん「私の解釈も少し原文から逸脱しているので、ここはシンプルに原文だけでいい」）。
