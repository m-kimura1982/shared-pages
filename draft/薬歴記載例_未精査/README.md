# 薬歴記載例（未精査）

加算ページを作るときに一緒に出した、薬歴記載例のたたき台を置く場所。**このフォルダの内容はまだ公開しない。**

## なぜ分けているか

薬歴の記載例は、薬歴の作法（確認と指導の書き分け、通則(5)の画一化回避、個別指導で指摘される書き方）が判断基準になる。算定要件を書いている流れのまま書くと精度が落ちるので、原文を読んだ勢いでたたき台だけ作り、精査は薬歴の目で別途行う。

記載例の正本は薬歴マニュアル（`yakureki/加算別記載一覧.html` の該当セクション、又は個別ページ）。加算ページには記載項目とリンクだけを置く。

## 流れ

1. `/加算ページ 〈加算名〉` が `〈加算名〉.md` をここに出す
2. 木村さんが精査する（削る・書き直す・そもそも載せないと判断する）
3. 通ったものを `yakureki/加算別記載一覧.html` の該当セクションに載せる
   - 記載例が3例を超える／注・区分で書き分けが要る／個別指導の指摘に踏み込む場合は個別ページに昇格
4. 加算ページのリンク先が個別ページに変わったら差し替える
5. 済んだ .md は削除する
