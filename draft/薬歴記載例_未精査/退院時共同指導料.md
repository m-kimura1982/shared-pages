## 記載例のたたき台

### 病院に赴いて共同指導した場合

```
【退院時共同指導】R〇.〇.〇 〇〇病院〇階カンファレンスルームにて実施。
出席：〇〇病院 主治医〇〇医師、病棟看護師〇〇、薬剤部〇〇薬剤師、当薬局薬剤師〇〇。
確認：入院中の処方は退院時処方のとおり。入院前の〇〇（薬剤名）は中止、〇〇へ変更されていた。
   服薬は現在看護師が管理しており、自己管理は未実施。嚥下は良好、粉砕の必要なし。
   同居の長女が退院後の薬の管理を担当予定。
指導：退院後の服用方法（〇〇は朝食後、〇〇は就寝前）と、〇〇（薬剤名）で注意する
   〇〇（副作用等）の初期症状について、患者と長女に説明した。
   〇〇があれば服用を続けたまま当薬局へ連絡するよう伝えた。
提供文書：退院後の服薬管理に関する情報提供書（写しを添付）。
同意：本人及び長女より、退院後の訪問薬剤管理指導について同意を得た。
```

### ビデオ通話で共同指導した場合（冒頭のみ差し替え）

```
【退院時共同指導】R〇.〇.〇 ビデオ通話（〇〇）により実施。
画面上での個人情報の共有について本人の同意を得たうえで実施した。
出席：（以下同じ）
```

## 判断に迷った点・確認してほしい点

1. **「確認」と「指導」の書き分け。** 上のたたき台は 出席者 → 確認 → 指導 → 提供文書 → 同意 の順にした。
   確認（入院中の処方変更・服薬管理者・嚥下）と、そのうえで行った指導を分けている。
   薬歴マニュアルの他の記載例と並びが揃っているか確認したい。
2. **出席者をどこまで書くか。** 摘要欄には「患者が入院している保険医療機関の保険医等の氏名」を
   入力するので、薬歴側でも氏名まで残すのが自然だと考えたが、レセプトと同じ内容を薬歴に
   二重に書くことになる。氏名まで残すか職種までにするかは運用の判断。
3. **提供文書の写しは「添付」が通知の言い方。** レセコン上の運用（PDFで保管するか紙で綴るか）が
   薬局によって違うので、記載例の中では「写しを添付」とだけ書いた。
4. **入院中２回算定する場合**（別に厚生労働大臣が定める疾病等の患者）の2回目の書き方は
   たたき台を作っていない。1回目との差分（前回の共同指導からの変化）を書く形になると思うが、
   対象疾病の一覧が手元の改定資料に入っていないので保留にした。
