# /照合 — 一次資料の照合係を呼ぶ

対象: $ARGUMENTS
（引数がなければ、直近で編集した .html。複数あれば1ページずつ別々に頼む）

1. 対象ページごとに **source-checker** エージェントを起動する（バックグラウンドで。複数ページなら並行してよい）。
   依頼文は「対象：<ページのパス> を正本と照合してください。」だけにする。こちらの狙いや気になっている点は書かない（先入観を渡さない）。
2. 報告が届いたら、**「不一致」「言い過ぎ・言い足りない」を自分でも正本で確かめてから**本人に出す（照合係の報告は判断材料。そのまま事実として伝えない）。
3. 出し方：
   - 確かめて正しかった指摘 → 直す案を「以前の記載／直した後」の対で示す
   - 書くかどうかが判断になるもの（例外の網羅など）→ 本人に聞く
   - 照合係の誤り → 「照合係の指摘のうち、○件は誤りだった」と一言添えて落とす
4. 直すのは本人の了承のあと。直したら /公開 の流れに乗せる。
