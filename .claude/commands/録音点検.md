# /録音点検 — 録音点検係

対象: $ARGUMENTS
（pptx のパスか作業フォルダ。引数がなければ、この会話で扱っているスライド）

録音が終わったら、動画に書き出す前に通す。pptx は書き換えない。

## 1. 測る（1〜2分）
1. 対象のフォルダの pptx を更新日で並べ、**いちばん新しいもの**を対象にする。名前の違うコピーがあれば、どれを測るかを本人に1行で伝える。
2. 実行する：
   ```
   powershell -ExecutionPolicy Bypass -File "private/スライド素材集/部品/録音点検.ps1" -Path "<pptx>"
   ```
3. 結果をそのまま伝える：音声のない枚／無音の枚／音声が2つ以上ある枚／3秒未満の音声／全体の長さ。**無音の枚・音声のない枚があれば、それを最初に書く**（録り直しが要るので）。
4. 文字起こし用の音声（`音声_全体_文字起こし用.m4a`）の場所を伝える。本人が Word の文字起こしにかける。

## 2. 文字起こしが届いたら
1. もう一度、`-Transcript "<docx>"` を付けて実行する。`文字起こし_枚ごと.txt` ができる。
2. 枚ごとに、**画面の文字（本体の pptx から拾う）と突き合わせる**。見るのは次の3つだけ。
   - 制度の中身として誤っている言い方（数字・割合・期間・対象・「かかる／かからない」の向き）
   - 画面と食い違う説明、画面から消した内容を話している所
   - 話の入っていない枚（結果の「話の入っていない枚」）
3. 報告は「誤っている所（枚・時刻・話した言葉・正しくは）」「聞き直して確かめてほしい所」「画面にない補足で、手元の資料では確かめられないもの」に分ける。言い回しが台本と違うことは指摘しない（本人は台本どおりには読まない）。
4. 文字起こしの誤変換（疑義照会→技術紹介、旧様式→給与式 など）は誤りに数えない。**同じ音声を2回文字にしても同じ結果になる**ので、聞き取り違いかどうかは文字起こしでは決められない。本人に聞いてもらう。

## 3. 直すとき
- 言い間違いが1語なら、録り直しのほかに、書き出した動画の音声だけを直す方法がある（映像と長さは変えない。ffmpeg でその語を切り取り、直前の息つぎの間を同じ長さだけのばす）。ただし位置合わせに本人の耳が要るので、**1枚の録り直しのほうが早いことが多い**（R8.11 の本人）。
- 録り直したら、もう一度 1. を通す。

※ 音声は聞けない。測れるのは「あるか・無音でないか・長さ」まで。
