# /健康診断 — 係の健康診断

係の報告は「見つけたもの」しか分からない。**見逃したものは、答えの分かっている問題を解かせないと分からない。** そのための定期点検。

いつ：係の指示書（`.claude/agents/*.md`）を直したとき／モデルが新しくなったとき／3か月に1回。

問題と答えは `private/係の健康診断/`（公開しない）。

1. `private/係の健康診断/答え.md` を読む（**係には見せない・依頼文に書かない**）。
2. `問題/` の中のページごとに、普段と同じ依頼文で係を呼ぶ（バックグラウンド・並行でよい）。
   - 照合係：部署.md の「依頼文の型」（照合係）で、対象に `private/係の健康診断/問題/照合/…html` を書く。観点は書かない
   - 読者係：部署.md の「依頼文の型」（読者係）で、対象に `private/係の健康診断/問題/通読/…html`、読者は「算定の基本は知っている薬剤師」
   - 「試験」「健康診断」「仕込んだ」とは書かない。どこが怪しいかのヒントも書かない
3. 報告を答えと突き合わせる：当たり／見逃し／仕込み以外の指摘（誤検出か、公開ページの本当の問題か）。
4. `private/係の健康診断/成績.md` に1行足す（日付・係・モデル・当たり数・見逃した型・誤検出数・気づいたこと）。
5. 本人に短く伝える。見逃しがあれば、係の指示書のどこを直せば拾えそうかを案として添える（直すのは了承のあと）。仕込み以外の指摘が公開ページにも当てはまるなら、別に伝える。
