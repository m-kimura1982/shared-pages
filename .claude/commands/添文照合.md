# /添文照合 — 電子添文の照合係を呼ぶ

対象: $ARGUMENTS
（引数がなければ、直近で編集した .html。複数あれば1ページずつ別々に頼む）

1. 対象ページごとに **label-checker** エージェントを起動する（バックグラウンドで。複数ページなら並行してよい）。
   依頼文は「対象：<ページのパス> を電子添文と照合してください。」と、設計メモなど決定済みの方針のパスだけにする。こちらの狙いや気になっている点は書かない（先入観を渡さない）。
2. 全員の報告がそろうまで本人に出さない（部署.md の「取りまとめ」）。
3. 「不一致」は、照合係が引用した原文で自分でも確かめてから直す。添文の版が古い・原文を開けていない指摘は、直さずに「確認できない」として扱う。
4. 本人に出すときは「直したこと」と「判断が要ること（3つまで）」の1回にまとめる。
