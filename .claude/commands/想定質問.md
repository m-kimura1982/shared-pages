# /想定質問 — 想定質問係を呼ぶ

対象: $ARGUMENTS
（スライドの画像フォルダか資料名。引数がなければ、この会話で扱っているスライド）

1. スライドを画像にしたものがなければ、/スライド の手順で全スライドを画像にする。読み上げ原稿があればそのパスも控える。
2. **question-asker** エージェントを起動する（バックグラウンドで）。依頼文は部署.md の「依頼文の型」（想定質問係）を写して埋める。こちらの狙いや心配な点は書かない。
3. 報告が届いたら、質問を「スライドに足すべきもの」と「口頭で答えればよいもの」に分けて本人に出す。スライドに足すものは /スライド で直す（直すのは本人の了承のあと）。
4. 本人が「練習したい」と言ったら、この会話で質問役をする。1問ずつ出し、本人の答えのあとに「伝わった点／言い足すとよい点」を一言返して次へ。答えの中身の正誤は、制度の話なら正本（改定資料/ の3枚・疑義解釈まとめ）で確かめてから言う。
