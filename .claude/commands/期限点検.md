# /期限点検 — 期限切れの点検係

対象: $ARGUMENTS（引数がなければ公開ページ全部。「90日」のように書いてあれば先を見る範囲にする）

```bash
cd "D:/☆shared-pages"
node tools-internal/check-dates.js            # 過ぎたもの＋60日以内に来るもの
node tools-internal/check-dates.js --days 90  # 先の範囲を変える
```

結果を次の3つに分けて本人に出す（全件を貼らない）：

1. **近く来る期限**（経過措置の終わり・届出の締め切りなど）→ 期限の前に、ページの書き方を「〜まで」から「〜以降は」に変える準備が要るか
2. **過ぎたのに今も続いているように読める記述** → 直す案つき（例：「〜までは要件を満たすものとみなす」が、期限後も現在形のまま）
3. **経緯として正しいので直さなくてよいもの** → 件数だけ

期限が過ぎた表（「○月まで／○月から」の2列など）は、古い列を消すか残すかを本人に聞く（窓口で前の月の分を扱うことがあるので、すぐ消すとは限らない）。
