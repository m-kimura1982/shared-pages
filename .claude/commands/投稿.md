# /投稿 — フォーラム投稿の下書き・推敲

対象（引数があれば題材・下書き、なければ会話中の依頼内容）: $ARGUMENTS

## 手順

1. **必ず先に読む（スキップ禁止）**：
   - `private/フォーラム投稿_スタイルガイド.md`
   - `private/フォーラム投稿_文体サンプル.md`（最低限 ①②③⑤⑥⑨）
2. 投稿タイプを判定する（Q&A／現場判断／注意喚起／運用案内／理念／事務向け）。スタイルガイドの該当する型の骨組みに沿って書く。
3. 書き始める前に「読者が一番誤解しそうな点」を1つ決め、冒頭に置く。
4. 算定可否を断定するのは、通知・疑義解釈・算定要件上の根拠を確認できた場合だけ。確認できない箇所は本文に断定で埋め込まず、**【要根拠確認】** を付けて別リストで示す。
5. スタイルガイド末尾の「投稿前チェックリスト」で自己点検してから下書きを提示する。
6. 提示するのは下書き全文＋（あれば）要根拠確認リスト。**投稿するかどうか・最終文面はユーザーが決める。自動投稿・外部送信はしない。**

## やらないこと

- サイトHTML資料の文体（常体・資料調）で書く
- 根拠のない算定可否の断定
- 締めの名言・過剰な励まし・ビジネス書調の表現
- private/ 配下の内容を公開ページやコミットに混ぜる
