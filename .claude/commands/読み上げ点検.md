# /読み上げ点検 — 読み上げ係を呼ぶ

対象: $ARGUMENTS
（資料名か作業フォルダ。引数がなければ、この会話で扱っているスライド）

1. 全スライドの画像が今のスライドと合っているか確かめる（作り直した後の画像を使う）。ノートの `## NN` の番号と画像の番号がそろっているかも見る。
2. **speech-reader** エージェントを起動する（バックグラウンドで）。依頼文は部署.md の「依頼文の型」（読み上げ係）を写して埋める。こちらの狙いや直したい所は書かない。
3. 報告が届いたら、指す場所・行の並び・色の呼び方を、自分でも画像で確かめてから反映する。制度の分け方や言い回しが、サイトや決めごとと違う提案は採らない（採らなかった理由を本人に一言）。
4. 直す前のノートは控えを残し、直したらスライドを作り直して、発表者ノートに正しい枚で入ったかを確かめる。

**いつ呼ぶか**：スライドのデザインや並びを変えたあと、ノートを書いた・大きく直したあと。収録の前には一度通す。デザインを直している途中では呼ばない（番号や画面が変わると提案がずれる）。
