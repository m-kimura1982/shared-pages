# /通読 — 初見の読者係を呼ぶ

対象: $ARGUMENTS
（引数がなければ、直近で編集した .html。「事務」「薬剤師」と添えてあれば読者の立場として渡す）

1. ページの種類を決める（加算の解説／チェックリスト／Q&A／薬歴マニュアル／ツール）。読者の立場の指定がなければ、事務向けのフォルダ（事務/）は事務スタッフ、それ以外は「算定の基本は知っている薬剤師」。
2. **first-reader** エージェントを起動する。依頼文は次の3行だけ（こちらの狙いや気になっている点は書かない）：
   ```
   対象：<ページのパス>
   読者：<立場>／ページの種類：<種類>
   ```
   事務と薬剤師の両方が読むページなら、立場を変えて2人並行で頼んでよい。
3. 報告が届いたら、引っかかった箇所ごとに原因を見立てて本人に出す：
   - **直したほうがよい**（読者が誤解する・必要な答えが無い）→ 直す案つき
   - **直さなくてよい**（ページの性質上それでよい。例：Q&Aで要件を網羅していない）→ 理由を一言
   - 「読み終えて理解したこと」が書いた意図とずれていたら、それを最初に出す
4. 文言をまとめて直すときは /推敲 に引き継ぐ（推敲は通読の報告を材料にする）。直すのは本人の了承のあと。
