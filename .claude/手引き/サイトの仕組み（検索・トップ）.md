# 検索の索引とトップページの仕組み

> CLAUDE.md から分けた細則（2026-11-17。文面はそのまま）。**検索の当たり方を直すとき・トップページを触るときに読む。**

## 検索の索引

- **サイト内検索と `ページ一覧.html` は、ページ名だけでなく各ページの見出しも探す。** 索引は `node assets/build-search-index.js` が `h1 / .card-title / .sub-title / .section-title / .tool-name / .item-heading` を集めて `assets/search-index.js` を作る（/公開 の中で走る）。見出しに出てこない言葉でも引っかけたいときは、そのページの `<head>` に `<meta name="search-keywords" content="湿布,貼付剤,前後7日" />` を足す。入口ページ（ハブ）はスクリプト側の SKIP で索引から外している（中身が他ページ名の並びなので、入れるとどの語でも上位に出て邪魔になる）。
- **検索は本文も探す（2026-11-12）。** 同じスクリプトが本文の索引 `assets/search-body.js`（約1.9MB・圧縮後 約420KB）も作り、検索を初めて使ったときにだけ読み込む。並べる順は 題名 ＞ 見出し・検索キーワード ＞ 本文。空白で区切った語は「すべて含む」ページだけを出す。全角英数と半角英数は区別しない。題名以外で当たったページは、開いた先でその語の場所まで進む。**探し方は `assets/search-core.js` の1か所だけ**にあり、共通ヘッダーの検索（site-search.js）とページ一覧.html の両方が呼ぶ（以前は別々に書いていて、ページ一覧だけ2語で0件になっていた）。自動生成の原文・疑義解釈・社内Q&Aの写し（genbun / gigi-list / qa-list）は本文の索引に入れない（正本のページで当たる）。
- **定型見出しは索引に入らない**（「関連する疑義解釈」「関連ページ」「原文を見る」「目次」など。`build-search-index.js` の `SKIP_TERMS`）。どのページにも同じ文字列で出る見出しはページを見分ける手がかりにならず、「疑義解釈」で検索したときに本命が埋もれるため。一方「レセプト摘要欄記載事項」「薬歴記載事項」は**残す**（「吸入 薬歴」のような2語検索で効くので消さない）。

## deploy.js

- `tools-internal/deploy.js` は新規HTMLをルート直下にコピーする作りのまま。フォルダ構成にした今は、コピー後に該当フォルダへ移動してリンクを直す必要がある（または手動で配置する）。公開は原則 `/公開` を使うので出番はほぼない。

## トップページ

- トップは2026-09-11にデザインを刷新（デザインルール.md の「トップとハブの見た目」）。**ヒーロー → 調剤報酬の棚6カード → 薬歴の棚2カード → 更新情報**。旧・二本柱の大型入口カードは、各棚の見出しの帯に置き換えた（同じ文字が2回出ていたため）。ヒーロー文言は「調剤報酬も薬歴も、『現場で使える形』に。」。
- **ヒーローの「最新の更新」はトップ下部の更新情報リストの先頭1件から自動で作る**（30日より前なら出さない）。更新を足すときは今までどおりリストに1件足すだけ。トップの更新情報には NEW を付けない（最新5件そのものなので意味が薄れる。NEW はハブと updates.html で効かせる）。
- **検索欄の下に「よく使う資料」のチップ5つ**（見出しは読者係が候補7つから選んだ。「ピックアップ」は下の PICK UP 注目情報とかぶる。チップの言葉は名詞の形でそろえる）（2026-11-08。読者係の通読で「用事から入れない」が一番の困りごとだったため）。入れ替えるときは index.html の `.task-list` の a を直すだけ。「最新の疑義解釈」は `#kai-latest`（疑義解釈まとめがいちばん新しい回に絞り込む）なので、回が増えても直さなくてよい。
- **スマホでは棚を2列のタイル（アイコン・題名・件数）にし、注目情報は1枚の面に3行**（2026-11-08。1列のカードでトップが5画面あったのを約3.8画面に）。PCの見た目は変えていない。
- ヒーロー右の「○件の資料から探す」の件数は page-meta から自動で数える。検索欄は本物の入力欄で、送信すると `ページ一覧.html?q=…` を開く。「最近見たページ」は直近3件だけをこの欄に出す（全件は共通ヘッダーの検索を空のまま開くと出る）。
