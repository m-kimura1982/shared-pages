# 摘要欄のページ・調剤報酬QA の決まり

> CLAUDE.md から分けた細則（2026-11-17。文面はそのまま）。**摘要欄（レセコメ）を扱うページを書くとき・調剤報酬QA に追記するときに読む。**

### 摘要欄（レセコメ）ページのルール

レセプト摘要欄の記載を扱うページでは、**コード番号ではなく「レセプト表示文言」を主役**にする。

- 表は「レセプト表示文言」（または「レセプト摘要欄コメント」）を主列に。コード列は原則のせない（レセコンが自動採番・自動付与するので実務で選ぶのは表示文言だから）。どうしても要るなら小さく従に。
- **列見出しに「（これを選択）」等の操作説明を付けない**（2026-07-23）。読みで呼び出して候補から選ぶ手順は現場が分かっているので不要。操作に触れる必要があるときは見出しではなく本文側に「次のいずれかを入力する」と書く。
- 表示文言は別表Ⅰの `c-disp` を一字一致で転記。固定プレフィックス（「該当する状態（…）：」）はグレー寄り、選ぶ可変部は太字・黒。薄すぎ厳禁。
- 加算ページ等で摘要欄が単発のときは、入力する表示文言だけを1行で明快に示す（例：「フォローアップを行った年月日」）。**「入力位置」は書かない**（レセコメは常に摘要欄で自明）。

### 調剤報酬QA（ナレッジ/調剤報酬QA.html）に追記するときの手順

Q&Aが増えたので、2026-07-23から検索窓・カテゴリ目次・NEWチップを載せている。追記時は次の3つを守る。

- **新しい `.qa` には `data-added="YYYY-MM-DD"` を付ける。** 追加から14日間だけ自動でNEWチップが出る（JSが判定。期限管理は不要）。
- **カテゴリを新設したら `<div class="card" id="c-○○" data-keywords="かなよみ">` の形で書く。** id は目次チップのリンク先、data-keywords は検索用のかな読み（漢字はかな検索に引っかからないため。薬剤名がカタカナなら本文で拾えるので不要）。目次チップと件数はカード見出しから自動生成される。
- **Q&Aは算定要件の解説ではない。** 聞かれていない要件を網羅的に足さない（読者は基本を知ったうえで質問してくる）。補足はその質問の答えを分かりやすくするときだけ。
- **掲載前の下書きと、載せないQ&Aは `private/QA保管庫.md` に置く**（2026-11-03）。イレギュラーな場面で、結論だけ読まれると誤読を招くもの（例：約束したフォローアップを来局時の対面で行う）はサイトに出さず、「載せない（聞かれたら答える）」に理由と一緒に残す。下書きを別ファイルに増やさない。
